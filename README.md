## 📦 安装方法

1. 将 `NK-AIGC-Comfyui` 整个文件夹放入：
   `ComfyUI/custom_nodes/NK-AIGC-Comfyui/`
2. 安装依赖（在 ComfyUI 根目录执行）：
   `pip install -r custom_nodes/NK-AIGC-Comfyui/requirements.txt`
3. 重启 ComfyUI。

## 🛠️ 节点使用说明

### 1. 南光AIGC-工作流自动关机
用于在整套工作流运行完毕后自动执行关机、重启或睡眠。
- **适用场景**：长时间批处理、夜间渲染、无人值守。
- **用法**：将本节点放在工作流末尾，把保存图像/视频节点的输出（或任意完成信号）连接到 **「触发」** 输入。工作流全部执行成功后，节点按设定的 **延迟秒数** 自动执行操作。
- **支持系统**：Windows / Linux / macOS。
- **前端功能**：提供状态显示和 **「取消自动关机」** 按钮（Windows 可取消，Linux/macOS 视系统支持而定）。

### 2. 南光AIGC-加载图像(遮罩)
支持图像上传、裁剪、RGB 转换、遮罩生成，输出图像、遮罩和文件名。
- **UI 操作**：
  - 点击 **📤 上传图像** 选择本地图片。
  - 调整 **裁剪 X / Y / 宽度 / 高度** 进行裁剪。
  - 点击 **🎨 RGB 转换** 或 **⬛ 生成遮罩** 切换处理模式。
- **输出端**：
  - `图像` (IMAGE)：裁剪后的 RGB 图像张量。
  - `遮罩` (MASK)：与图像尺寸一致的遮罩张量。
  - `文件名` (STRING)：当前图像文件的基名。
